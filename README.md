# library-catalog
Небольшое учебное приложение для создания и просмотра электронного каталога библиотеки. Проект использует базу данных SQLite и ORM SQLAlchemy для хранения информации об авторах и книгах.

Каталог позволяет просматривать список книг и проверять их наличие в библиотеки. Интерфейс реализован с помощью NiceGUI.
# Основные функции
- Хранение информации об авторах и их книгах
- Связь "автор - книги" (один ко многим)
- Отображение доступности книг (в наличии/отсутствует)
- автоматическая инициализация базы данных
- Работа с базой данных SQLite через SQLAlchemy
# Возможности системы 
- Просмотр списка всех авторов
- Просмотр книг выбранного автора
- Поиск книг по названию
- Отображение статуса книги (в наличии / на руках у пользователя)
- Отображение пользователя, у которого находится книга
# Структура базы данных
Автор
- id - идентификатор автора
- name - имя автора
Книга
- id - идентификатор книги
- title - название книги
- is_available - наличие книги в библиотеки
- author_id - ссылка на автора

Связь реализована через relationship и ForeignKey.
# Инициализация базы данных
При первом запуске:
- создаются таблицы authors и books
- база данных автоматически наполняется начальными данными

# Структура проекта 
- app.py — запуск веб-приложения (NiceGUI)
- create_library.py — модели базы данных и инициализация SQLite
- library.sqlite — файл базы данных (создаётся автоматически)
- requirements.txt — зависимости проекта
# Запуск проекта
1. Установить зависимости:
   pip install -r requirements.txt
2. Запустить приложение:
   python app.py
3. Открыть браузер:
   http://localhost:8080
