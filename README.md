# library-project
Небольшое приложение для просмотра электронного каталога библиотеки. Позволяет просматривать список книг и выполнять фильтрацию по различным параметрам. Интерфейс реализован с помощью NiceGUI и отображается в виде веб-вкладки в браузере.
# Основные функции
- Просмотр каталога книг
- Поиск книг по автору
