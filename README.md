# 📚Каталог библиотеки 
Веб-приложение для управления библиотечным каталогом. Позволяет добавлять книги, просматривать авторов и читателей, выдавать книги и отслеживать их статус.
Проект использует базу данных SQLite, ORM SQLAlchemy для работы с данными и NiceGUI для веб-интерфейса.
# Возможности системы 
- Добавление новых книг с указанием автора и статуса
- Просмотр всех авторов и их книг
- Выдача книги читателю с вводом фамилии, имени и телефона
- Просмотр всех читателей и книг, которые у них на руках
- Поиск книг по названию
- Отображение книг по статусу: в библиотеке / на руках
- Журнал выдачи книг (Borrowing) с датами
# Структура базы данных
Author — авторы книг
- id — идентификатор
- name — имя автора (уникальное)

Book — книги
- id — идентификатор
- title — название
- is_available — статус (True — в библиотеке, False — на руках)
- author_id — ссылка на автора

User — читатели
- id — идентификатор
- name — имя читателя (уникальное)

Borrowing — журнал выдачи
- id — идентификатор
- book_id — ссылка на книгу
- last_name — фамилия читателя
- first_name — имя читателя
- phone — телефон читателя

# Интерфейс 
Приложение разделено на четыре вкладки:
- Добавление книги — форма для добавления новой книги с выбором автора и статуса
- Авторы — список авторов, у каждого можно открыть список его книг и выдать книгу читателю
- Читатели — список читателей и книги, которые у них на руках
- Книги — поиск книг по названию, а также разбивка всех книг по статусу
